## UI / icons — js/sprites/ui.js (agent H)
Node icons (24×24), ids prefixed `node_`: battle (crossed swords), elite (skull with crown),
boss (big horned skull), rest (campfire), treasure (wooden chest with gold), shrine (glowing
stone totem), event (scroll with question mark), merchant (market stall / coin bag), puzzle
(rune tablet), start (jungle hut), heart (glowing crimson heart-tree), mystery (swirling
purple question mark), training (target with arrow), trap (spiked bear trap), locked (grey cloud).

Item icons (16×16), ids prefixed `item_`: sword, staff, bow, dagger, axe, spear, mace, wand,
whip, claws, leather_armor, chain_armor, plate_armor, robe, hide_armor, shell_armor, ring,
amulet, charm, feather, tooth, idol, boots, cloak, gem.

Potion icons (16×16), ids prefixed `potion_`: red, blue, green, yellow, purple, orange, elixir
(rainbow), phoenix (feather in bottle).

Status icons (16×16), ids prefixed `status_`: poison (green drop), burn (flame), bleed (red
drop), stun (yellow stars), weak (down arrow), guard (shield), haste (double arrow), regen
(green plus), slow (snail/hourglass), shield (blue barrier), rage (red up arrow), blind (eye crossed).

Misc (16×16): `icon_gold` (coin), `icon_xp` (star), `icon_hp` (heart), `icon_mp` (blue drop),
`icon_gear` (settings gear), `icon_book` (compendium book), `icon_trophy` (achievement trophy),
`icon_skull` (defeat), `icon_map`, `icon_lock`, `icon_check`, `icon_arrow_right`.

Decorations: `deco_leaf` (16×16), `deco_vine` (16×32 hanging vine), `deco_flower` (16×16),
`deco_mushroom` (16×16), `deco_torch` (16×24), `deco_rock` (24×16), `deco_tree` (32×48 jungle
tree), `deco_fern` (24×16), `deco_totem` (16×32).
